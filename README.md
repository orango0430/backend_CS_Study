# 백엔드 개발자를 위한 CS 스터디

> 스프링 부트 프로젝트를 진행하면서 함께 알아두면 좋은 CS 지식들을 정리한 저장소입니다.

## 목차

### 운영체제 (Operating System) — Week 1
- [01. CPU](./operating-system/01-cpu.md) - CPU 구조, 스케줄링, 컨텍스트 스위칭, I/O 바운드
- [02. 메모리 (Memory)](./operating-system/02-memory.md) - 메모리 계층, 캐시, 가상 메모리, JVM, GC
- [03. 프로세스 (Process)](./operating-system/03-process.md) - 프로세스 구조, 상태, PCB, IPC, MSA
- [04. 스레드 (Thread)](./operating-system/04-thread.md) - 동시성, 동기화, 스레드 풀, DB 락

### 네트워크 (Network) — Week 2
- [01. OSI 7계층](./network/01-osi-7-layer.md) - 7계층 역할, 캡슐화, TCP/IP 4계층 비교
- [02. TCP & UDP](./network/02-tcp-udp.md) - 3-way/4-way handshake, 흐름/혼잡 제어, TCP vs UDP
- [03. HTTP 심화](./network/03-http.md) - 메서드, 상태코드, 쿠키/세션, HTTP 버전 변화
- [04. HTTPS & DNS](./network/04-https-dns.md) - 대칭키/공개키, TLS handshake, DNS 조회
